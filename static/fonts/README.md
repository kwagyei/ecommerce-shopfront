# Fonts

Grotesk, extended-Latin subsets).

| File | Family | Licence |
| --- | --- | --- |

| `hanken-grotesk-latin.woff2`, `hanken-grotesk-latin-ext.woff2` | Hanken Grotesk, variable weight (400 and 500 used), by Hanken Design Co. | SIL OFL 1.1 |
